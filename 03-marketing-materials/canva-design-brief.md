# PureHeal — Canva Design Brief for WhatsApp Post Images

Use this brief to create all 6 post images in Canva. Each section gives you the exact canvas size, colors, text, and layout hints.

---

## 🎨 Brand Tokens (copy these into Canva's Brand Kit)

| Token | Value | Use for |
|---|---|---|
| Primary | `#DCEFF2` | Backgrounds, large color blocks |
| Deep Botanical | `#1C2A2E` | Body text, dark overlays |
| Leaf Green | `#6E8B6A` | Accent text, icons, checkmarks |
| Natural White | `#F7F7F2` | Text on dark backgrounds, cards |

**Fonts**
- Heading → **Playfair Display** (or Cormorant Garamond)
- Body / bullets → **Lato** (or Open Sans)
- Highlight callouts → any handwritten/script font (e.g. Pacifico, Dancing Script)

---

## 📐 Canvas Sizes

| Format | Size | Use for |
|---|---|---|
| WhatsApp Post | **1080 × 1080 px** | Posts 1–5 |
| WhatsApp Status | **1080 × 1920 px** | Post 6 (Status cards) |
