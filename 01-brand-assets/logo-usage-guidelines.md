# Logo Usage Guidelines

## Approved Usage
- Keep clear space equal to the height of the letter "P" around the logo.
- Use primary dark logo on light backgrounds.
- Use white logo on dark/photographic backgrounds with contrast.

## Do Not
- Stretch, rotate, or recolor the logo arbitrarily.
- Add shadows/outlines.
- Place logo on cluttered backgrounds without contrast.

## File Naming Convention
- `pureheal-logo-primary.png`
- `pureheal-logo-light.png`
- `pureheal-logo-icon.png`
